# 数据限制与偏差

- yfinance 是非官方 Yahoo Finance 工具，可能受许可条款、限流、字段变化和服务稳定性影响。
- 默认示例 CSV 只是格式样例，不代表恒生指数或恒生中国企业指数的完整、当前或历史成分。
- 只有当前指数成分时，历史回测存在幸存者偏差；系统会显示“本测试使用当前指数成分股回溯历史，可能存在幸存者偏差”。
- Yahoo 的历史财务公告日、自由流通股本、退市/清盘/私有化事件和指数历史成分覆盖可能不足。缺失时相关因子禁用，不回填未来值。
- 复权价格已经反映公司行动，价格收益不再额外加入现金股息，避免重复计算。
- Yahoo 基准代码在部署前应通过小范围真实请求验证。未经验证的代码不硬编码为可用基准。
- Streamlit Community Cloud 本地 SQLite 不是永久存储。请下载备份并在重启后恢复。
- 系统以活动证券池版本、市场数据修订版、统一截止日、风险规则和风险快照编号标识一次可复现计算。只有这五项一致时，两个页面结果才应直接比较。
- Yahoo成功更新、失败股票补抓、证券池重新导入或风险规则修改都会形成新的输入状态，结果合理变化不属于随机不稳定。
- Yahoo分批更新期间下游快照和新实验会被阻止；若进程异常中断超过六小时，页面会明确警告旧的运行状态，使用者应先检查更新日志。
- 本工具不构成投资建议；历史结果不保证未来表现。
