# 回测与验证方法

每个有效月末依次执行：读取当时及以前的数据 → 执行实验冻结的风险规则 → 只对通过股票计算因子 → 横截面评分 → 生成下一月持仓 → 观察下一月复权价格收益 → 计算 Rank IC 和组合收益。

Rank IC 是当月全体有效股票综合得分与下一月收益的 Spearman 相关，不只使用最终入选股票。有效股票不足或横截面无变化时跳过并记录原因。

Rank IC 页面使用平均值、ICIR、正值比例和最近 12 月均值生成固定规则的通俗说明；月度组合回测使用年化收益、波动率、夏普、最大回撤、换手率、交易成本拖累和基准收益生成固定规则说明。两者均为描述性研究结论，不构成收益预测或投资评级。

港股增强模型每个月末按当时的因子综合得分重新排名，选择用户指定的前 3–15 名；不使用未来的下一月收益，也不使用事后 Rank IC 选股。资金配置由股息率与逆波动率两部分组成，两项比例由用户设置且必须合计 100%。文章方案一基准单独运行：月频调仓、传统日波动率筛选、红利/连续分红/市值/流动性过滤，最终按股息率加权；不使用因子总分和日频 CV 代理。

组合约束默认包括单股上限、行业上限、前五大合计上限、最低目标权重及换手限制。无法分配的资金保留为现金。交易成本由用户提供，不永久写死税费。

每次手动调权都会创建独立实验编号，冻结当时使用的因子权重、风险规则、月度股票池和下一月收益。Rank IC和回测必须选择同一实验编号，结果写回同一档案；完整ZIP可用于复核和备份。

风险过滤已经成为因子计算的直接上游，因此最新选股不再通过两份CSV事后取交集。只有完成Rank IC与回测并在实验档案批准的正式实验可以生成最新选股；人工公告复核和计划权重仍不属于量化回测结果。

若要求从 2016 年开始计算完整 Yahoo 基础10因子组合，建议原始价格和分红历史至少从 `2011-01-01` 开始抓取。2011–2015 年仅用于形成三年分红、连续分红和价格窗口，组合净值从用户选择的回测开始日期累计。`gross_value` 是未扣交易成本的动态调仓累计净值，`net_value` 是扣除交易成本后的累计净值；页面同时记录每月新进入、退出和继续持有名单。
