# 回测与验证方法

每个有效月末依次执行：确定当月可用股票池 → 读取当时已知数据 → 计算因子 → 横截面评分 → 生成下一月持仓 → 观察下一月复权价格收益 → 计算 Rank IC 和组合收益。

Rank IC 是当月全体有效股票综合得分与下一月收益的 Spearman 相关，不只使用最终入选股票。有效股票不足或横截面无变化时跳过并记录原因。

港股增强模型使用 13 项因子，默认选前 30 名，资金配置可选股息率、逆波动率或两者各 50%。文章方案一基准单独运行：月频调仓、传统日波动率筛选、红利/连续分红/市值/流动性过滤，最终按股息率加权；不使用 13 因子总分和日频 CV 代理。

组合约束默认包括单股上限、行业上限、前五大合计上限、最低目标权重及换手限制。无法分配的资金保留为现金。交易成本由用户提供，不永久写死税费。

滚动验证至少需要 6 年月度历史：前 5 年为初始训练期，随后窗口作为样本外验证，之后逐月或按验证块向前扩展。参数只能由训练窗口确定，最终排行榜只使用样本外指标。全样本最优参数不能被描述为历史可实现结果。
