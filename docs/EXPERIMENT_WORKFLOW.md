# 版本化实验流程

1. 在数据中心导入CSV，确认活动证券池版本；完成Yahoo更新并确认市场数据修订版不再处于运行状态。
2. 在“股票池与风险过滤”选择因子模式，检查规则并点击“应用并保存”。页面使用统一截止日并显示风险快照编号；下载CSV只用于检查，不再参与事后取交集。
3. 在“因子实验室”填写实验备注和因子权重，创建新实验。系统生成统一日期版本名和唯一 `experiment_id`，并冻结证券池版本、数据修订版、统一截止日和风险规则；随后逐月先做风险过滤，再计算因子及下一月收益。
4. 在“Rank IC测试”选择同一实验编号。调整最少有效股票时先查看预览，确认后点击“运行并保存”；只有明确提交后，综合Rank IC、子因子比较与月度明细才写回该实验。
5. 在“月度组合回测”选择同一实验编号，设置3–15只、开始日期、成本、持仓上限和资金配置。控件变化不会自动覆盖历史归档；点击“运行并保存”后，月度收益、净值、换手、调仓进出和持仓才写回该实验。
6. 在“实验档案与对比”比较多轮手动实验的核心指标、配置、权重、共同区间净值与回撤。完整实验可下载ZIP，其中包含配置JSON、风险过滤、因子、Rank IC、回测和持仓CSV。
7. 只有完成回测的因子增强实验可以批准为正式实验。“最新选股结果”只读取这套正式实验被冻结设置，对最新已通过风险过滤的股票生成名单，并提供人工公告复核表。

实验综合得分用于辅助比较，不是预估收益。手动全历史实验不自动等同于严格样本外结果；重复观察同一历史区间后调参仍可能过拟合。当前导入成分股回溯历史的幸存者偏差提示保持不变。
