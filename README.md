# 港股红利低波实验室

**HK Dividend Low Volatility Lab** 是一个独立的 Streamlit 港股研究网站，用于真实 Yahoo / CSV / SQLite 数据上的证券池管理、逐月风险过滤、Yahoo 基础10因子与完整13因子评分、Rank IC、月度回测、版本化实验对比和最新选股人工复核。

## 安装与启动

要求 Python 3.11 或 3.12。

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
streamlit run streamlit_app.py
```

Streamlit Community Cloud 的主文件固定为 `streamlit_app.py`。项目不需要密钥；Yahoo 只在用户点击“开始更新 Yahoo 数据”后请求，不自动刷新。

## 推荐流程

1. 在“数据中心”上传 `data/sample_hk_universe.csv` 或自定义证券池 CSV。
2. 导入后系统自动生成全部港股代码。若要从 2016 年开始进行完整10因子月度回测，原始数据开始日期设为 `2011-01-01`，再手动更新 Yahoo 数据；逐股失败会显示并写入日志。
   同页可更新已实际验证的 Yahoo 基准代码 `^HSI`（恒生指数）和 `^HSCE`（恒生中国企业指数）。两者于 2026-08-06 通过五日请求验证，后续仍可能因 Yahoo 变更而失效。
3. 在“股票池与风险过滤”选择并保存规则；基础模式不要求自由流通市值。后续实验会在每个月末先执行该规则，再计算因子。
4. 在“因子实验室”填写实验名称、选择模型、确认权重合计为100%，创建独立实验编号并计算风险过滤后的月末因子快照。
5. 在“Rank IC测试”选择同一实验编号，检验综合得分和各子因子的排序能力；结果自动写回实验档案。
6. 在“月度组合回测”选择同一实验编号，设置2016年开始、每月动态选择3–15只及股息率/逆波动率比例；回测、净值和调仓明细自动写回实验档案。
7. 在“实验档案与对比”比较多轮手动实验并下载完整ZIP；批准一套完成回测的正式实验。
8. “最新选股结果”只读取正式实验，对最新已通过风险过滤的股票选股，并提供人工公告复核与建仓清单。

## 证券池 CSV

必须包含：`symbol,name,sector,security_type,board,index_membership,effective_date,end_date,source`。代码统一为 Yahoo 港股格式，例如 `700`、`0700`、`700.HK` 均转为 `0700.HK`。示例文件仅展示格式，不冒充完整指数成分。

## 数据与存储

价格收益和波动使用复权价格；股息率使用独立现金分红和未复权月末价格，避免重复计入分红。财务值只有在 `published_date` 不晚于因子月末时使用。SQLite 通过主键 upsert 去重。

Streamlit Community Cloud 的本地 SQLite 只是运行缓存，不可视为永久存储。请定期下载数据库备份；应用重启后可在数据中心上传恢复。Yahoo/yfinance 可能限流、改字段或暂时失败，系统不会伪造数据，也不会以演示值替代结果。

## 模型与验证

Yahoo 基础10因子只使用价格、成交量和现金分红：三年平均股息率、最近12个月股息率、连续分红稳定性、三年股息增长率、60日与120日波动率、60日下行波动率、120日最大回撤、日频波动稳定度和20日平均成交额。默认权重依次为 24%、12%、6%、5%、18%、12%、8%、6%、4% 和5%。

完整13因子在上述基础上加入股息支付率可持续性、现金流覆盖能力和自由流通市值，需要另行导入具备公告日期的财务与股本数据。每一轮手动实验按 `experiment_id` 独立保存，不会被后续同模式实验覆盖。

全站数据表采用中文标题显示，同时保留标准英文字段 CSV 供程序处理。Rank IC 与组合回测的自动结论由固定、可复核的描述性规则生成，不是投资评级。风险过滤已成为因子计算的直接上游，不再依赖两份CSV事后取交集。

REIT 默认允许进入 Yahoo 基础10因子候选池，但仍须通过价格、交易活跃度、停牌、成交额、派息与公司事件过滤，并在最终建仓前人工复核分派、利率、资产估值和负债风险。

13 项定义见 [因子定义](docs/FACTOR_DEFINITIONS.md)。Rank IC 是当月全部有效股票得分与下一月复权收益的 Spearman 相关。文章方案一基准与增强模型严格分开；增强结果不是参考文章原始结果。

回测遵循月末信号、下一月持仓与收益对齐。实验档案中的历史收益不是未来预估收益，不应只按最高历史收益选择参数。当前成分回溯可能造成幸存者偏差，未来价格、股息、指数成分、退市信息和未公告财务值不得用于过去。

## 测试

```bash
pytest -q
```

单元测试使用固定模拟数据，不依赖实时 Yahoo。真实 Yahoo 冒烟测试需另行手动执行；网络失败只应产生数据源警告。部署前还需实际验证计划使用的恒生指数和国企指数 Yahoo 代码。
